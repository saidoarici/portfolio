# Publishing this as a GitHub profile portfolio

GitHub shows a special profile README when a public repository has the same name as the account.

For the account `saidoarici`:

1. Create a new **public** repository named `saidoarici`.
2. Upload the contents of this folder to the repository root.
3. Keep the `assets/` and `projects/` paths unchanged.
4. Commit `README.md`; GitHub will display it on the profile page.
5. Review the screenshots and commercial naming permissions before publishing.

The Turkish version is available through `README.tr.md`. The default profile language is English for a wider professional audience.
