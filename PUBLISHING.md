# Showing this portfolio on a GitHub profile

GitHub shows a special profile README when a public repository has the same name as the account.

For the account `saidoarici`:

1. Keep this `portfolio` repository public and pin it on the GitHub profile.
2. Create a public repository named `saidoarici` only if a profile README is also desired.
3. In that profile README, add a short introduction and link to this repository.
4. Keep the `assets/`, `projects/`, and `scripts/` paths unchanged here.
5. Review commercial naming permissions before publishing future additions.

The Turkish version is available through `README.tr.md`. English remains the default repository language for a wider professional audience.
